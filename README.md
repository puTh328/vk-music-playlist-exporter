VK Music Playlist Exporter

**Экспорт названий песен из VK Музыки в текстовый файл для переноса плейлиста в Spotify.**

 О проекте

VK Music Playlist Exporter — это JavaScript-скрипт, который собирает названия песен и имена исполнителей из списка композиций в VK Музыке и сохраняет их в текстовый файл `vk-playlist.txt`.

Скрипт автоматически прокручивает список композиций, собирает доступные данные, удаляет дубликаты и формирует список, который можно использовать для переноса музыкальной коллекции в Spotify.

 Возможности

🎵 Сбор названий песен и имён исполнителей.

🔄 Автоматическая прокрутка списка для загрузки новых композиций.

♻️ Удаление повторяющихся записей.

📄 Экспорт результатов в текстовый файл.

🌐 Поддержка кириллицы и других символов.

⏱️ Ограничение времени выполнения для предотвращения бесконечной прокрутки.

 Технологии

- **JavaScript** — основная логика скрипта.
- **DOM API** — поиск музыкальных композиций на странице.
- **Browser APIs** — прокрутка страницы, создание и скачивание текстового файла.
 
 Как использовать

1. Открой VK Музыку в браузере.
2. Перейди к списку песен, который хочешь экспортировать.
3. Открой инструменты разработчика клавишей `F12`.
4. Перейди во вкладку **Console (Консоль)**.
5. Вставь код скрипта и запусти его.
6. Дождись завершения сбора композиций.
7. Найди скачанный файл `vk-playlist.txt`.

 Формат результата

Каждая песня записывается в формате:

```text
Artist 1 - Song Title 1
Artist 2 - Song Title 2
Artist 3 - Song Title 3
```

Полученный список можно использовать как источник данных для поиска композиций в Spotify или других музыкальных сервисах.

⚠️ Ограничения

- Скрипт зависит от структуры интерфейса VK Музыки и используемых HTML-селекторов.
- Собираются только композиции, доступные в загруженном списке и распознанные скриптом.
- Максимальное время работы — 5 минут.
- Скрипт экспортирует только названия песен и исполнителей, но не аудиофайлы.
- Автоматическое создание плейлиста в Spotify не предусмотрено.

🔒 Безопасность

Скрипт работает в браузере на открытой странице VK Музыки и не требует передачи пароля или токена Spotify. Перед запуском любого кода в консоли браузера рекомендуется ознакомиться с его содержимым.
